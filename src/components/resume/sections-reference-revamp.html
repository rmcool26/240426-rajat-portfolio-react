🔧 PAGE + PRINT CLASSES — Sirf ek baar lagani hain, sections ke saath nahi 
/* ── PAGE WRAPPER (SCREEN) ── */
.page {
  width: 8.5in;
  height: 11in;
  margin: 0 auto 20px;
  background: #FFFFFF;
  padding: 0.5in 0.55in;
  box-shadow: 0 8px 40px rgba(20, 20, 40, .08);
  page-break-after: always;
  overflow: hidden;
}
.page:last-child { page-break-after: auto }

/* ── PRINT ── */
@page { size: Letter; margin: 0 }

@media print {
  body { background: #fff; padding: 0 }
  .page { box-shadow: none; width: 100%; min-height: auto; margin: 0 }
}

How to use: Ye CSS apni resume file ke <style> mein ek baar daalo. Sections ke HTML <div class="page">...</div> ke andar aayenge. Print ke liye @page aur @media print block zaroori hai — inke bina Ctrl+P pe 2 pages nahi aayenge.
