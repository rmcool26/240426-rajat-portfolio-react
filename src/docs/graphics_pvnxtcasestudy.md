# Graphics Brief — pvNXT Case Study

Project: Rajat Mishra / rmcool26 Portfolio  
Page: pvNXT Solar Suite master case study  
Purpose: Create clear, premium, visual-heavy graphics so the case study is easy to understand and not boring to read.

---

## 0. Main Goal

The viewer should understand this in 30 seconds:

```txt
Before pvNXT:
Solar workflows were scattered across calls, WhatsApp, Excel, manual site visits and disconnected tools.

After pvNXT:
Rajat helped design a connected solar product suite across EPC teams, consumers, installers, field teams, proposals and monitoring.
```

Graphics should support this story:

```txt
Messy workflow → Connected product system → Rajat’s design process → Shipped products → Real outcome
```

---

## 1. Visual Style Direction

### Overall look

Use a clean, premium, modern SaaS case-study style.

Keywords:

```txt
Clean
Calm
Premium
Readable
Visual-heavy
Solar/product-tech
Not childish
Not over-corporate
```

### Recommended style

- Light neutral / warm off-white background.
- Soft shadows.
- Rounded cards.
- Thin connector lines.
- Minimal icons.
- Real product screenshots inside clean browser/device frames.
- Use small labels and short captions.
- Do not overload with text.

### Suggested colors

Use colors close to the portfolio/product feel:

```txt
Background: #F8F5EF / #FAF7F1 / #FFFFFF
Text dark: #111111 / #1F1F1F
Muted text: #6B6B6B
Primary accent: Indigo / Blue / Purple accent
Solar accent: Soft yellow / amber only as highlight
Success accent: Green only where needed
Error/problem accent: Soft red only for “messy/problem” states
```

### Typography guidance

- Use clean sans-serif type.
- Keep headings bold and short.
- Avoid tiny unreadable screenshot labels.
- If text is inside graphic, it must still be readable at portfolio size.

### Image export requirement

Please export each graphic as:

```txt
SVG preferred for diagrams
PNG preferred for screenshot/mockup composites
2x resolution PNG if raster
Transparent background only if needed
```

Recommended width:

```txt
Desktop graphics: 1600px wide minimum
Mobile/crop-safe version: 900px wide if required
```
