### Flagship Case Study: pvNXT Solar Suite (`/case/terranxt`)
A full solar-industry product ecosystem built from scratch for Terranxt — turned WhatsApp/Excel/manual site visits into one connected suite for EPCs, consumers and installers.

- **Role:** UI/UX Design Lead, Terranxt · 2022 — Now
- **Format:** Web portals + mobile apps, Live product, **FITT IIT Delhi incubated**
- **Stats:** 4+ EPCs, 6+ Real users, 50+ Screens shipped, 10–15 min Roof analysis

**The Mess Before pvNXT:** leads from calls, site details via WhatsApp, analysis in separate tools, manual proposals, installers updating via phone calls, no unified project view.

**The Connected System — sub-products in the pvNXT ecosystem:**
- **pvNXT Studio** — EPC workspace for leads, roof analysis, proposals, projects
- **pvNXT Connect** — consumer app for estimate, compare, request, track installation
- **pvNXT Go** — installer app to receive tasks, upload proof, update progress
- **Proposal System** — clean solar proposals from real project data
- **Field App** — field teams capture site details in one visit
- **SCADA Monitoring** — plant monitoring, alerts, O&M workflows

**Rajat's role:** Worked with real EPC teams to map manual workflows in FigJam → defined product architecture, named/structured the "Studio/Connect/Go" family → designed mid-fi & hi-fi Figma screens, early HTML/CSS/Bootstrap builds → led developer handoff, QA, and demos at IIT Delhi FITT.

**Process:** Decode real workflow → Structure the system → Design the product (mid-fi then hi-fi) → Ship with the team.

**Key design decisions:**
- Role-based views instead of one common dashboard (consumer/EPC/installer need different info)
- Mid-fidelity before visual polish (structure first)
- Reusable components from day one (product became a suite)
- Proposal clarity over technical overload (build consumer confidence, avoid jargon)

**Key learnings:** Complex products become usable when roles are clear; mid-fidelity saves time on messy workflows; a design system helps teams ship faster, not just decoration.
